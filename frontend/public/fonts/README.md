These unmodified variable WOFF2 fonts are served locally by VeloRay. Their licenses are included alongside the font files.

- **Inter 4.1**, by Rasmus Andersson: [upstream](https://github.com/rsms/inter/tree/v4.1), `InterVariable.woff2`; upstream commit `e3a3d4c57d5ecc01453a575621882a384c1995a3`. License: `Inter-LICENSE.txt` (SIL Open Font License 1.1).
- **Vazirmatn 33.003**, by Saber Rastikerdar: [upstream](https://github.com/rastikerdar/vazirmatn/tree/v33.003), upstream `fonts/webfonts/Vazirmatn[wght].woff2`, shipped as `Vazirmatn-Variable.woff2`. License: `Vazirmatn-OFL.txt` (SIL Open Font License 1.1).

Icons use the bundled Lucide SVG components. No icon font or third-party font service is required.
